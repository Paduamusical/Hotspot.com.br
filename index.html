Base de integração com PHP

Abaixo está uma estrutura inicial para ligar o frontend a um backend PHP responsável por gerar cobrança PIX real via banco ou gateway.

Exemplo backend
<?php header('Content-Type: application/json'); // Exemplo simples de endpoint para gerar cobrança PIX // Integre aqui com seu PSP/banco: Gerencianet, Efí, Mercado Pago, Asaas, PagSeguro, etc. if ($_SERVER['REQUEST_METHOD'] === 'POST') { $input = json_decode(file_get_contents('php://input'), true); $nome = $input['nome'] ?? 'Cliente'; $valor = $input['valor'] ?? '5.00'; $plano = $input['plano'] ?? 'Plano Rápido'; $txid = 'HSP' . rand(10000000, 99999999); // Aqui você chamaria a API do PSP para gerar a cobrança PIX real // Retornando qr_code, copia_cola, txid e status echo json_encode([ 'success' => true, 'txid' => $txid, 'nome' => $nome, 'plano' => $plano, 'valor' => $valor, 'status' => 'PENDING', 'qrCodeText' => '00020126580014BR.GOV.BCB.PIX0136pix@seudominio.com.br520400005303986540' . str_replace('.', '', $valor) . '5802BR5915HOTSPOT CENTRAL6009SAO PAULO62070503' . $txid . '6304ABCD' ]); exit; } echo json_encode(['success' => false, 'message' => 'Método inválido']);
Observações
Como gerar QR Code PIX real?

O ideal é usar um PSP ou banco com API PIX. O backend PHP cria a cobrança, recebe o payload EMV e envia ao frontend para renderização do QR Code.

Como liberar o hotspot após o pagamento?

Após receber webhook de pagamento aprovado, seu PHP pode acionar API, script ou integração com Mikrotik para remover bloqueio e associar a sessão ao plano comprado.

Posso usar este HTML como base de produção?

Sim. Esta interface já está pronta como base visual responsiva. Para produção, conecte os botões ao seu endpoint PHP, implemente autenticação, logs e validação real de webhook.

O QR Code aqui é funcional?

Sim, ele gera um QR baseado no payload PIX criado no frontend. Em produção, substitua o payload mock pelo retorno oficial do seu gateway PIX.
