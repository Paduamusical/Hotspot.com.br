Base de integração com PHP

Exemplo estrutural para você transformar este frontend em um sistema funcional com backend PHP.

<?php
// exemplo simples de endpoint para criar cobrança PIX
header('Content-Type: application/json');

$plano = $_POST['plano'] ?? '1 Hora';
$valor = $_POST['valor'] ?? '9.90';
$cliente = $_POST['cliente'] ?? 'visitante';

// aqui você chamaria seu PSP/gateway PIX
// salvaria no banco: pedido, txid, status, mac, ip, plano e data

echo json_encode([
  'success' => true,
  'txid' => uniqid('pix_'),
  'plano' => $plano,
  'valor' => $valor,
  'pixCopiaECola' => '000201...SEU_CODIGO_PIX...',
  'status' => 'pending'
]);
?>

Depois, crie um endpoint de webhook em PHP para receber a confirmação do pagamento e executar a liberação do usuário no hotspot ou no servidor Radius.
